# Stack Implementation Assignment

## About the Project
This project is based on the implementation of Stack Data Structure using Java. It demonstrates the working of Stack and its LIFO (Last In, First Out) principle.

The assignment focuses on understanding basic stack operations and solving problems using stacks.

## Programs Included

### 1. Stack Implementation
Implementation of a Stack with basic operations:
- Push()
- Pop()
- Peek()
- Display()

### 2. Reverse a String
Reverses a given string using the Stack data structure.

### 3. Palindrome Check
Checks whether a given string is a palindrome using Stack.

### 4. Find Middle Element
Finds the middle element of a Stack using a Linked List.
